# UI Reference

`yes-stems-ui-reference.png` is the target design for the YES Stems desktop UI.

It is the visual north star the app's layout is built against: a teal/cyan accent
on a deep navy shell, a centered mode dropdown in the title bar, a left setup rack
(source / mode / options / run), a center analysis stage (tabs, waveform, info strip,
per-stem preview, transport), a right extraction-report rack, and a trust-badge footer.

Not every element maps 1:1 to backend capabilities; where the design shows data we can
produce honestly (stem peaks, file sizes, durations) it is wired to real values, and the
browser-only preview seeds a representative demo state so screenshots match this reference.
